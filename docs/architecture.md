# System Architecture

The **Binjwa AI Cost Platform** follows a modern, scalable backend architecture built heavily on Python and NoSQL technologies.

## High-Level Architecture

1. **Client Layer**: 
   - Browsers, Mobile Apps, or internal scripts connecting via HTTP/REST.
   - Swagger UI automatically generated by FastAPI for testing.

2. **API Layer (FastAPI)**:
   - Request routing via `APIRouter`.
   - Data validation and serialization using `Pydantic` schemas.
   - Error handling using `HTTPException`.

3. **Database Layer (MongoDB)**:
   - PyMongo client is used to establish a persistent connection.
   - Separate collections for: `users`, `organizations`, `employees`, `ai_models`, `tokens`, `client_admins`.

## Folder Structure Logic (`backend/app`)
- `/api`: Contains all route definitions grouped by domain (e.g., `token.py`, `employee.py`).
- `/schemas`: Contains Pydantic models mapping to the database schemas and request payloads (e.g., `TokenCreate`, `TokenUpdate`).
- `/database`: Connects to MongoDB and initializes the `collections`.
- `/services`: Reserved for complex business logic, background tasks, and seed scripts.
- `main.py`: The entry point for Uvicorn, registering all routers and starting the FastAPI application lifecycle.
